# 更新日志

## [1.0.0] - 2024-10-28

### ✨ 新增功能

#### 广告类型支持
- ✅ 开屏广告 (SplashAd)
  - 全屏沉浸式体验
  - 倒计时跳过功能
  - 完整的曝光/点击监测

- ✅ Banner 广告 (BannerAd)
  - 灵活的尺寸配置 (320x50, 728x90 等)
  - 自适应屏幕宽度
  - 自动加载和刷新

- ✅ 插屏广告 (InterstitialAd)
  - 可关闭的对话框模式
  - CTA 操作按钮
  - 半透明背景

- ✅ 激励视频 (RewardedVideo)
  - 完整视频播放
  - 5秒后可跳过
  - 完成观看获得奖励

- ✅ 原生广告 (NativeAd)
  - 灵活的布局支持
  - 图文并茂展示
  - 与应用界面融合

- 🚀 智能缓存系统
  - 30分钟自动过期
  - LRU 淘汰机制
  - 磁盘持久化

- 📥 预加载机制
  - 后台异步加载
  - 批量预加载支持
  - 优先级队列

- 🔄 错误重试
  - 指数退避算法

- 📊 完整监测
  - 曝光追踪

  - 错误上报

  - 实时竞价支持
